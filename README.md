# ITA Digital: Conectando a Fé e Ação Social

Site institucional do Instituto Templo da Alegria (ITA) Estrutural e do Projeto Purim.

## 🌐 Site no ar
[www.ita-estrutural-bsb.com.br](https://www.ita-estrutural-bsb.com.br)

## 🛠️ Tecnologias
- Next.js
- React
- Tailwind CSS
- Neon (PostgreSQL)
- Supabase (Storage)
- Cielo (Link de Pagamento)
- Vercel (Hospedagem)

## ✨ Funcionalidades
- Páginas institucionais (Home, Quem Somos, Projetos, Contato, Notícias)
- Sistema de doações (Pix, Débito e Crédito)
- Painel administrativo para gerenciamento de conteúdo
- Galeria de fotos dinâmica
- Sistema de notícias

## 🚀 Como rodar o projeto
```bash
npm install
npm run dev
